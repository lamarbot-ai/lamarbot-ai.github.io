Privacy Policy

Last updated: October 21, 2026

Lamarbot Gmail Access is a private tool run by Lamar Oliphant for his own use. It is not available to the public.

Data accessed

With the account owner's consent, the tool uses the Gmail API to read, search, label and send email, and to receive new-mail notifications. It accesses only Google accounts that the owner has explicitly connected.

How data is used

Email data is used only to provide personal assistant features to the account owner, such as summarizing new mail, finding messages and sending replies the owner asks for. Data is not sold, used for advertising or shared with third parties, except the AI model provider that processes requests on the owner's behalf.

Storage and security

OAuth tokens are stored in the operating system's secure keychain on the owner's computer. Message content is processed on demand and is not copied into a separate database.

Google API Services User Data Policy

The tool's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.
